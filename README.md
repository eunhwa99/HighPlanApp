# High Plan
- Android application project in 2020.

## Function
- Timetable with Calendar
- ToDoList
- Diary
- User Customized Settings
  - Color Setting
- Description of how to use this App

## Tech Stack
### Library
- [ColorPicker](https://github.com/skydoves/ColorPickerView)
- [material](https://github.com/material-components/material-components-android)
- [gson](https://github.com/google/gson)
### Database
- SharedPreferences
  - Save Color Setting
  - Save TimeTable
  - Save ToDoList
  - Save Diary
